NarrowGate 多尺度 EMA 状态空间：十个 Half-Life、45 个配对到底在测什么

Last materially modified: 2026-08-29

TL;DR：45 个配对不是 45 条策略，而是一套描述“市场运动形状”的坐标系

NarrowGate 的 Full-Multiscale 研究把同一个因果可见信号同时交给十个反应速度不同的指数移动平均（Exponential Moving Average，EMA），再把任意一条快线与一条慢线配成一对。它想测的不是“哪条均线最会预测涨跌”，而是：一次增加库存的 maker 成交发生时，市场的短期运动相对中长期背景处在什么阶段，这种状态是否足以改变下一次允许继续加仓前的 cooldown duration。

结论先说清：十个 half-life 产生的 45 个 pair 是候选状态，不是 45 次独立下注；cross、distance、slope、curvature、expansion 与 persistence 描述的是一对时间尺度之间的几何关系，也不自动等于动作价值。trade flow 与 depth 只在后置的增量层加入，用来检验它们在 campaign 与 EMA 表示之上是否还有额外信息。

本文解释公开实现与冻结研究合同中的状态空间。最终经济证据仍只到历史 Development：30 个 family-specific 日期、3,516 个机会的嵌套时间序列样本外研究已经完成，但 BUY 与 SELL 都没有通过冻结门槛；没有 final refit、Validation、sealed holdout、action 或 live 权限。实验的精确对照应理解为“实验冻结时的 exact owner baseline”，不是对当前 live 状态的声明。

系列总览见 NarrowGate Full-Multiscale：从多尺度 EMA 到 Boolean Cooldown 的一次阴性研究。本文只讨论研究方法和历史证据，不构成任何交易建议。

1. Half-life 回答的是“记忆衰减多快”，不是“预测未来多久”

设某个市场通道在时刻 $t_i$ 的最新因果可见观测为 $x_i$，半衰期为 $h$ 的 EMA 状态记作 $E_h(t_i)$。公开实现使用实际经过的时间，而不是假定每次更新严格等间隔：

$\Delta ti=t_i-t{i-1}$ 是两次有效观测之间真正过去的秒数，$\lambda_{i,h}$ 是旧状态的保留权重。经过恰好一个 half-life，即 $\Delta t_i=h$，旧状态权重变成 $1/2$；经过两个 half-life，变成 $1/4$；经过三个，变成 $1/8$。

以 $h=8\text{s}$ 为例，4 秒以后旧状态权重约为 $2^{-1/2}=0.707$，8 秒以后为 $0.5$，16 秒以后为 $0.25$。这就是 half-life 最直接的含义：它规定过去信息以多快速度淡出，而不是宣称策略要预测未来 8 秒，也不是说 cooldown 必须等 8 秒。

研究的基础市场网格是完成后的 100ms 窗口，但实现会显式标记 source gap、stale 与未观测窗口；未观测值不会用零填充，也不会偷偷重复上一条观测。EMA 只在通道确实可观测时更新，衰减系数使用真实 $\Delta t_i$，所以一次丢失或跳过的窗口不会被误当成“又看到一个相同价格”。100ms 是状态采样合同，不是经济动作期限。

但 45 个 pair 越多，事后挑赢家的自由度也越大。因此 Full-Multiscale 没有先在全部 30 天上找一对最好看的均线，再把它包装成样本外结论；每个 outer-training period 内的 feature census、支持检查与筛选都只能在更早的 inner folds 中完成。45 是可进入搜索的全集，不是事后保留的 45 个结论。

5. 从 mid EMA 到 trade/depth：为什么后置加入很重要

状态空间不是一开始就把所有信息搅在一起。公开实现把通道按信息层次组织：基础层包括 mid；较浅的盘口层加入 spread、best bid/ask quantity、BBO imbalance 与 microprice deviation；更深的 M2 层才加入 aggressive buy/sell quantity、signed flow、trade count、run length、top-k depth、depth imbalance、depth shape，以及 displayed depletion/refill 等状态。

研究候选层级与此相呼应：E1 先保证 45 个 mid-EMA ordering 全部可进入 inner-fold 搜索；E2 再要求每个 pair 的 direction、recency、persistence、distance、normalized distance、slope、curvature、convergence 与 expansion 都真实可达；E3 才允许高阶 Boolean interaction；M2 最后加入非 mid 的 trade/depth predicates。

这种顺序回答的是“新增信息有没有增量价值”。如果直接让一个巨大的 trade/depth 规则集与 baseline 比，任何正点估计都可能同时来自 EMA、campaign age、动作频率或更复杂的搜索。把 M2 放在最佳 campaign/EMA 表示之后，才有机会把增量写成：

只有 $\Delta_{M2}$ 的冻结门槛通过，而且最终规则真的使用 trade/depth predicate，才可以说这些后置状态贡献了增量信息。Full-Multiscale 的最终 Development 结果并没有给出这种授权。

6. 读这些状态时最容易犯的四个错误

  • 把 half-life 当成预测 horizon。$h$ 只控制历史权重衰减；未来经济标签、cooldown duration 与 campaign 终点是另外的时间概念。
  • 把 45 个 pair 当成 45 条独立策略。它们是一个相关性很强的候选特征全集，必须在嵌套时间序列搜索中控制选择偏差。
  • 把 golden/death cross 当成完整状态。direction 相同但 age、persistence、distance velocity 与 curvature 不同，可能代表完全不同的阶段。
  • 把 unobserved 当成零或 false。没有看见交叉、窗口缺失、通道 stale 都是证据不可用，而不是“条件没有发生”。

7. 这项状态表示最后证明了什么

它证明了工程和研究合同层面的可实现性：十个 half-life、45 个 pair 与成套方向状态可以在因果完成窗口上递推；每个 outer fold 可以只用自己的过去段筛选；trade/depth 可以作为后置增量层；三值缺失语义能够进入同一套 policy evaluator。

它没有证明“多尺度 EMA 能稳定赚钱”。历史 Development 的最强 BUY E3 候选出现了值得保留的正点信号，但 day-level simultaneous interval、冻结 hierarchy、tail 与 lifecycle gates 没有全部通过；SELL 没有正的 non-baseline candidate。因此最严谨的结论仍是：这套状态空间产生了一个后续可以独立确认的 hypothesis，但没有获得 research-supported action 或 live authority。
