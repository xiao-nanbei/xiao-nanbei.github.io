+0.458577 USDC/day 为什么仍是阴性结果

Last materially modified: 2026-08-29

TL;DR：正数描述样本，研究门槛决定证据权限

问题：一个策略每天少亏 0.458577 USDC，四个时间折叠全部为正，还保留了 97.29% 的成交，为什么研究报告仍把它判为阴性？

结论：因为“阴性”描述的不是点估计的正负，而是预先冻结的 Development gate 是否全部通过。BUY E3 的 primary day-level simultaneous interval 跨零，状态语义增量的区间也跨零，feature hierarchy、tail 与 lifecycle gates 失败；SELL 则连 terminal 点估计都是负数。一个好看的均值不能补偿任何 hard gate。

证据边界：结果来自 30 日 family-specific historical Development、四个 expanding outer folds 和 20 个 out-of-fold，简称 OOF，测试日。队列是同毫秒歧义删失的 modeled replay，baseline 是实验冻结时的 exact owner baseline。本文不提供 receive-time、strict exchange queue、最终 refit artifact、Validation、sealed holdout、action 或 live 证据。

状态：supported_sides=[]，没有 final refit，Validation 与 sealed holdout 未读，research_supported_promotion=false、action_authorized=false、live_authorized=false。

系列总览见 NarrowGate Full-Multiscale：从多尺度 EMA 到 Boolean Cooldown 的一次阴性研究。项目源码见 NarrowGateMaker。

1. “+0.458577”究竟是什么

Full-Multiscale 研究让一个有界的三值 Boolean policy 根据 campaign、多尺度 EMA、trade 与 depth 状态选择 cooldown duration，再用 repeated sequential full-path replay 重建订单、成交、库存和 campaign 终局。BUY 侧最强点信号是 E3_HIGHER_ORDER_BOOLEAN。

若第 $d$ 个测试日中，候选与 baseline 的 terminal value 分别是 $Y_d(E3)$ 和 $Y_d(B_0)$，20 个 OOF 测试日上的点估计可以写成：

它回答的是：“在这组冻结的 Development 测试日上，E3 相对实验冻结时的 exact owner baseline 平均改善了多少。”它没有自动回答：“真实增量必然大于零吗”“换一组日期还会成立吗”“尾部风险是否安全”“这个 artifact 可以部署吗”。

2. BUY E3 的完整数值，不只是一行 headline

指标 Exact B0 BUY E3 变化
Terminal value -2.904117 USDC/day -2.445540 USDC/day +0.458577 USDC/day
Closed-campaign value -3.018197 USDC/day -2.414185 USDC/day +0.604012 USDC/day
Fills 8,565 8,333 -232，保留 97.29%
Positive outer folds — 4 / 4 四折均值均为正
Positive OOF days — 13 / 20 仍有 7 日没有改善

按 modeled replay denominator 计算，terminal loss 的点估计减少 15.79%，closed-campaign loss 减少 20.01%。这是一个真实存在、值得保存的 Development signal，不应被一句“失败了”抹掉。

但它也不是一个完整的成功声明。13/20 日为正意味着 7/20 日不为正；4/4 fold 均值为正说明信号没有只集中在一个 outer fold，却不能替代对日级波动、尾部和多重候选搜索的控制。

5. 先控制“少做一点”，再问状态有没有价值

E3 从 8,565 笔 baseline fills 降到 8,333 笔。为了检查改善是否只是来自减少参与，研究构造了与 E3 匹配 action rate 和 duration distribution 的控制策略。该控制只有 8,312 笔 fills，比 E3 还少，但 terminal uplift 只有 +0.264689 USDC/day。

6. Hard gates 不是加权平均题

Full-Multiscale 的 scorecard 先检查 hard gates，再考虑 ranking。可以把逻辑简化为：

只要其中一项为 False，ranking_score 就应保持 null。更高的平均 PnL、更多正 fold 或更好的 fill retention 都不能通过加权把 hard failure 抵消掉。

BUY E3 的公开 scorecard 结论包括：conditional net-value lower bound 不为正、negative-terminal protection 和 q10 shortfall protection 的下界为负、repair-event 与 censoring-avoidance 方向失败；同时，冻结 hierarchy 的第一道 E1_FULL_EMA_BANK vs B0 没有通过。

因此 E3 的 candidate class 是 hard_gate_failed。这不是“综合得分差一点”，而是至少一个不可补偿条件未满足。

7. Feature hierarchy 为什么会否决后层 winner

E3 是高阶 Boolean interaction 层，位于完整 EMA bank 的 E1 和方向特征层 E2 之后。冻结 hierarchy 要求依次建立：

第一步失败以后，后层的漂亮点估计仍可以保留为探索性 hypothesis，却不能被写成“full-multiscale representation 已获得确认”。这是为了控制在大量 EMA pair、predicate 与规则组合中选择 winner 所产生的偏差。

研究真正否决的不是 +0.458577 这个观测值，而是把它升级为 confirmatory evidence 的资格。

8. SELL 是另一个不能被平均掉的检查

SELL E3 相对 exact B0 的 terminal increment 是 -0.009708 USDC/day，fill retention 为 101.18%，20 个测试日中有 12 日改善。正日比例超过一半，却仍与负总体点估计并存；这提醒我们，日的幅度和方向都重要，不能只数胜率。

SELL 的 simultaneous lower bound、tail 与 lifecycle gates 也失败，E1、E2、M2 和其他简单候选的 terminal point increment 同样为负。因此 SELL 没有 non-baseline successor candidate。

BUY 与 SELL 分开 gate 后，两侧都不受支持。把它们 pooled 在一起，只会遮蔽不同方向上的动作语义与风险结构。

9. “阴性”不等于“没有任何信息”

这个结果至少留下三条有价值的信息。第一，BUY E3 的正点估计跨四个 outer fold 出现，不像单一日期制造的偶然峰值。第二，它保留了大部分 fills，并且超过 action-matched control，说明值得作为未来确认 hypothesis 保存。第三，day-level 与 semantic uncertainty、hierarchy、tail 和 lifecycle 共同指出，当前证据不够稳定，不能晋级。

所以最准确的结论不是“E3 无效”，也不是“E3 已成功”，而是：E3 是有经济意义的 Development point signal，但没有通过预先冻结的 confirmatory contract。

如果未来要确认它，必须先冻结 E3 的特征、规则、threshold、duration action 和 statistical contract，再使用与当前 Development 不同且具有相应权限的新证据。不能回到这 30 日上缩窄规则、换 primary block、修改 hierarchy 或重调 action rate。

10. 从研究结果到权限，不能跳级

当前证据只到 learning-algorithm OOF Development：每个 outer fold 学到的是一个 fold-specific policy。研究没有生成一个全 Development final refit 后的 exact final artifact，更没有证明那个 artifact 在 Validation 或 sealed holdout 上成立。

因此权限链在 Development gate 处停止：

historical Development OOF
-> hard gate failed
-> no final refit
-> Validation unread
-> sealed holdout unread
-> no research-supported action
-> no live authority

这条边界也解释了为什么文章始终使用“实验冻结时的 exact owner baseline”，而不把历史研究对照写成今天的 current live state。研究结果描述被冻结的比较，不能替代独立的 operational authority。
